# Taint Analysis: Tracking Untrusted Data Through a Program

A 10-page technical deep-dive covering the mechanics, real-world security applications, and analytical limitations of static and dynamic taint tracking.

## What's Inside
* **Core Mechanics:** Modeling Sources, Sinks, Propagation, and Sanitizers.
* **Static vs. Dynamic Analysis:** Comparing codebase coverage against runtime precision and false-positive rates.
* **Practical Applications:** Vulnerability detection (SQLi, Command Injection, XSS), CI/CD integration, binary reverse engineering (Angr, Taintgrind, Triton), and Automated Exploit Generation (AEG).
* **Analytical Challenges:** Handling false positives/negatives, dynamic code execution (`eval`), reflection, and implicit control-flow dependencies.
